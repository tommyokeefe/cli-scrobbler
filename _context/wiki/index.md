## Quick Summary

**cli-scrobbler** is a Go CLI tool that scrobbles albums from a user's Discogs collection to Last.fm. It targets Last.fm enthusiasts who listen to physical media. The project is distributed via Homebrew and Scoop, has a small but growing user base, and is heading toward a richer TUI experience.
